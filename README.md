# MINION 的仓库 · 茶小满奶茶店开业落地页（接单样品）

一个手机优先的门店开业活动页样品：虚构奶茶店「茶小满」，用于展示落地页接单效果。

## 页面包含
- 顶部：开业活动横幅 + 第二杯半价 + 活动倒计时
- 中间：招牌菜单，划线价 / 活动价并排展示
- 底部：领券按钮，点击有提示反馈
- 店名、价格、活动时间都可按真实店铺替换

## 说明
- 单文件 HTML，手机浏览器打开即看，无需服务器
- 本页面为接单样品，店铺为虚构，仅作展示

A mobile-first landing page sample for a milk tea shop opening campaign (fictional shop, demo only).
